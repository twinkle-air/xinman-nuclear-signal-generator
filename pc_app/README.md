# 核信号工作台

智能仿核信号发生器的 PC 上位机首版。当前版本完整支持设备模拟模式，用于在硬件未接入时验证数据导入、参数配置、噪声、泊松事件、脉冲堆积、双通道控制与报告导出。

## 运行

```powershell
cd pc_app
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m nucsignal_app.main
```

也可以运行根目录的 `run.ps1`。

## 已实现

- 简洁的五区主界面：信号源、波形预览、通道参数、设备状态、运行控制。
- CH1红色/CH2蓝色高对比度波形，支持滚轮缩放、拖动平移、双击或按钮复位。
- 左侧五步纵向流程图，显示信号源、参数、连接、下发和启动的当前进度。
- Am-241、Cs-137、Co-60、K-40、Na-22、Ba-133、Eu-152、I-131、Tc-99m共9种典型峰模板，以及256/1024道能谱导入。
- 逐点 TXT/CSV/XLSX 波形导入、50 MSPS 重采样和 14 bit 量化。
- 单指数/双指数脉冲、固定周期/泊松到达、PILEUP/NON_OVERLAP。
- 白噪声/带限噪声、基线漂移、削顶与堆积统计。
- 0.1–5 V幅度、1–100 μs FWHM直接调节、10 μs–10 ms周期/平均间隔及实时重复频率显示。
- 双通道独立参数、模拟连接、原子下发、启动与停止。
- HTML 验证报告和原子写入的双通道 CSV 波形导出。
- 验证报告记录配置频率、FWHM、泊松间隔CV与指数CDF KS-D，并明确区分软件模型和硬件实测。
- 文档规定的二进制帧、CRC32以及分片/粘包解析器。
- USB CDC硬件串口选择、HELLO握手、ACK重试和分块波形传输。
- ST-Link VCP模式、全部COM口显示（ST-Link优先排序）、手动端口输入及115200/460800/921600波特率选择。
- 连接和波形下发在后台执行，界面保持响应，并区分“Windows枚举”“串口打开”“V1握手成功”。
- 醒目的“下发波形与参数”按钮以及0–100%传输进度。
- 左下角“使用教程”按钮，提供快速开始、参数、文件、硬件、验收和故障排查六章教程。

## 连接硬件

### 当前单通道台架适配状态（2026-10-18）

V0.8.0图形界面已接入F405-B2.0.0单通道台架，用户已完成GUI启停、外部停止、断开/关闭及重连、30分钟运行与3轮断电启动验收，详见[板级验收记录](../stm32_firmware/docs/基础方案板级验收记录.md)。V0.8.1完成本轮波形补测；V0.8.2修复底栏沿用HELLO历史FPGA文本的问题，台架底栏改用实时状态，回读失败显示状态未确认；新EXE仍需用户实物复核显示。端口按实际枚举选择，台架固定115200，不把COM号当作硬件身份。

### 单通道台架操作

#### V0.9.0新增N3单通道核信号

兼容原B2固定周期台架，识别`F405-N3.0.0`后才显示实时随机到达、能谱幅度和均匀噪声。须配套新V3 FPGA；新功能尚待实物验收，不能继承旧版硬件测试结论。完整产物、下载及回退步骤见[单通道核信号调试方案](../stm32_firmware/docs/单通道核信号_N3_调试方案.md)。

N3中周期栏在随机模式表示平均间隔（128–10000 μs）；每1 μs一次事件判断，属于离散泊松近似。噪声为±峰值码的有界均匀噪声，不是高斯RMS。能谱上传256项分位表，支持内置示意谱及导入谱，按谱轴满量程映射至最大幅度码；不支持逐点波形上传。预览与实际输出使用同一整数参考算法，但预览不属于实测；真实输出由FPGA实时计算。保持码值控制，未加入正式伏特校准。

以下为B2的原操作范围；N3沿用恢复、提交、回读、启停和串口线程流程，并在SET/COMMIT前完成能谱表上传与校验。两种硬件模式均只有CH1，原双通道模拟保留。

1. 选择“单通道台架”和CH340实际串口并连接。HELLO必须是`bench=true, channels=1, firmware=F405-B2.0.0`；其他硬件入口识别到同一固件也自动切换。未知台架版本拒绝操作。
2. 连接后自动RECOVER及GET_STATUS，不自动启动。状态区显示错误、FPGA在线、generation、活动码值参数和安全旁路；CH2显示“当前硬件不支持”。
3. 仅设置DAC基线码、幅度码差、周期和τ。基线与幅度均为0–255且和≤255，周期128–10000 μs，τ为1–100 μs，周期≥5τ。未校准，不进行伏特换算。
4. “提交台架参数”依次RECOVER → SET(CH1) → COMMIT → GET_STATUS，检查回读参数与generation；成功后才允许START。不发送波形上传或CH2命令。
5. 单一串口工作线程每约200 ms查询状态，操作与轮询串行。STOP或外部停止后需重新提交，错误不自动恢复或重新启动。
6. 断开/关闭窗口时尝试STOP并回读；停止未确认时明确提示。轮询失败不保留缓存RUN作为界面真值。
7. 台架预览纵轴为DAC码、1 μs更新步进，仅为参数模型；实际电压、极性和波形质量由示波器确认。当前固件不支持的噪声、随机、双通道和上传功能均禁用；返回模拟模式可使用原功能。

下面保留通用V1流程，适用于实现对应功能的固件，不是本轮bench操作步骤。

1. STM32固件实现并遵循 [`protocol_v1.md`](protocol_v1.md)。
2. 选择连接方式：STM32原生`USB CDC`，或具有VCP功能且已接好UART TX/RX/GND的`ST-Link VCP`。
3. 在界面右上角选择对应模式；ST-Link VCP还要选择与STM32 UART一致的波特率。
4. 点击“刷新串口”，选择对应COM端口，然后点击连接。
5. HELLO握手成功后，设置波形并点击橙色“下发波形与参数”。
6. 进度达到100%且状态显示已配置后，点击“启动输出”；停止时点击“安全停止”。

