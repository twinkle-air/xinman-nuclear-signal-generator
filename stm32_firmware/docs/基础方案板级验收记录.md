# 单通道基础方案板级验收记录

整理日期：2026-10-18。证据来自本聊天中用户提供的终端、下载器和示波器截图，以及用户对停止、启停和断电复测的现场确认；本次整理未重新操作硬件。通过范围为下面列出的台架测试点，不是全量参数组合或计量校准。

## 1. 已验证配置

- PC → CH340/USART1 → 外接STM32F405 → SPI → 逻辑派FPGA-G1 → H5直插ATK-MO8008 V3.3单通道DAC。
- STM32：`build-bench/nucsignal_f405.hex`，HELLO为`F405-B2.0.0`、`channels=1`、`bench=true`。
- FPGA：`../../FPGA_firmware/基础方案/通信联调_时序诊断/impl/pnr/g1_dac_spi.fs`，协议版本`FPGA-2.0.0`，工作程序User Code `0x0000743C`。
- FPGA DAC更新步进1 μs；phase=10更新数据的时序诊断版已在本轮硬件测试中使用。原`通信联调`目录保留，不以原FS替代本轮版本。
- 最新确认CH340为COM3；端口会随USB重新枚举变化，每次明确指定实际端口，不把COM3视为硬件身份。
- `safety_bypass=true`，A/B/PG为null；未安装的安全输入不在通过范围内。

## 2. 实物检查结果

| 项目 | 现场结果与边界 |
|---|---|
| 通信与控制 | HELLO、RECOVER、SET、COMMIT、START、状态轮询、STOP可运行；示波器确认实际输出和停止基线 |
| DAC时序对照 | 原SPI版本起始深尖峰和恢复段下跳，在时序诊断版多档观察中未再见；支持接口时序排查方向，不独立证明器件采样沿或根因 |
| 停止与恢复 | 正常STOP、STM32 PA0停止、G1 F10停止及后续恢复已观察 |
| PC失联 | 强制结束控制进程后实际停止；随后状态ERROR/TRANSFER，RECOVER后可运行；未精确测量停止延迟 |
| FPGA自主停止 | GDB暂停STM32，确认DHCSR S_HALT=1且IWDG冻结位=1；输出回基线并保持，恢复后可运行；未精确测量250 ms延迟 |
| 连续运行 | 一次300秒运行，用户报告波形无异常，末尾正常停止；不等于长期可靠性证明 |
| 重复启停 | 5轮，每轮5秒运行、约3秒停止间隔；用户确认各轮实际正常启停，末轮STOP返回running=false |
| 非法幅度组合 | baseline=128、amplitude=128：PC参数解析拒绝；绕过PC校验直接发送SET后STM32返回invalid channel parameters or output envelope，前后IDLE/OK/fpga=true，generation=19及原参数不变；未覆盖所有非法字段 |
| 断电恢复 | Flash写入校验成功；断电后不重新下载，读到User Code 0x0000743C；RECOVER后输出与停止正常；最后一次完整断电复测用户确认通过 |

### 幅度码检查

基线码16，四档按用户此前执行顺序对应56/112/168/224。使用顶端值减底端值，避免把噪声极值混为脉冲幅度。

| 幅度码 | 基线/V | 底端/V | 相对基线幅度/V |
|---:|---:|---:|---:|
| 56 | 2.88 | 1.44 | 1.44 |
| 112 | 2.88 | 0.08 | 2.80 |
| 168 | 2.88 | -1.28 | 4.16 |
| 224 | 2.88 | -2.64 | 5.52 |

四点支持码值与幅度大致线性；电位器、探头倍率、负载等条件未形成校准记录，不能由此提供准确伏特设定。

### 衰减参数检查

记录的是最低点开始到半幅恢复点的时间，理论为`τ × ln(2)`，不是τ本身，也不是示波器自动上升时间。

| τ设置/μs | 半幅时间实测/μs | 理论/μs |
|---:|---:|---:|
| 6 | 4.6 | 4.16 |
| 12 | 8.4 | 8.32 |
| 24 | 17.2 | 16.64 |
| 48 | 33.4 | 33.27 |
| 96 | 67 | 66.54 |

各档约保持2.88 V基线、5.52 V幅度。照片和手动游标用于初步工程检查，不给出计量误差指标。

### 周期与基线检查

- 周期500 μs：游标500 μs，自动2.00 kHz，有平稳基线。
- 周期128 μs、τ24 μs：游标128.4 μs，自动128 μs/7.81 kHz，未见明显堆积；游标差不单独用作时钟误差。
- 周期10 ms：游标10.04 ms，自动10 ms/100 Hz；125 kSa/s下窄脉冲最低点可能漏采，该图幅度值不作验收。
- 幅度码112、τ24 μs，基线码64：基线1.64 V，底端-1.12 V，幅度2.76 V，半幅16.8 μs。
- 同条件基线码128：基线约40 mV，底端-2.72 V，幅度2.76 V，半幅16.8 μs。

## 3. Flash固化及故障记录

已成功配置：

| 项 | 值 |
|---|---|
| Device | GW2A-18C |
| Cable frequency | 2.5 MHz |
| Access Mode | External Flash Mode |
| Operation | exFlash Erase,Program,Verify thru GAO-Bridge |
| Flash | Generic Flash |
| Start Address | 0x000000 |
| FS | 时序诊断目录的impl/pnr/g1_dac_spi.fs |

成功日志：检测SPI Flash标识`0xEF4017`，显示`Program and Verify flash successfully.`。桥接加载过程User Code `0x0000B8DF`不是最终工作程序身份；断电启动后读取工作程序为`0x0000743C`。芯片照片后缀未可靠辨认，不凭图补全厂商订货型号。

- 非桥接`exFlash Erase,Program,Verify`曾报SPI Verify failed，不能因为随后Finished而记为通过。
- 0.5 MHz读回ID/User/Status异常；本台下载链路保留已验证2.5 MHz，不假设越低越可靠。
- 固化后曾出现FPGA-OFFLINE，单独复位STM32和F10均未解决；后续检查接线并重新上电后RECOVER成功。没有充分证据把原因确定为接触不良或启动时序。
- 最后完整断电复测通过，支持当前接线与配置下可恢复；保留上述间歇失败记录。

官方依据：[逻辑派MDK开发中的外部Flash固化示例](https://wiki.lckfb.com/zh-hans/fpga-ljpi/m1/m1.html)。这里只采用外部Flash操作方式，未引入其Cortex-M1/ITCM流程。

## 4. 上位机接入前差异及实施清单（历史方案）

接入前的旧版`pc_app/src/nucsignal_app/device.py`的SerialDevice.transfer先DATA_BEGIN/CHUNK/END，再发送两路ChannelConfig，缺少台架RECOVER及运行期状态心跳。以下保留实施清单；V0.8.0已增加独立台架流程，实际结果见第5节。

接入的最小范围：

1. 增加显式“单通道台架”连接模式，115200波特率，串口可选择；验证bench=true、channels=1及固件版本。
2. 连接后执行RECOVER与GET_STATUS；显示真实设备状态、FPGA在线、generation、活动码值参数及安全旁路。
3. 控件仅提供基线码、幅度码、周期μs、τμs；限制与设备一致。CH2、上传、噪声、随机事件和伏特设定在该模式禁用。
4. 停止后SET→COMMIT→活动参数回读确认；只有配置成功后允许START。
5. 单一串口工作线程串行处理操作与约250 ms状态轮询，避免并发读写。运行中持续GET_STATUS，满足已实现2秒PC超时机制；外部停止/ERROR/离线及时反映到界面，不把缓存RUN当真值。
6. STOP成功以设备回读为依据；退出/断开时尝试STOP，失败明确显示，设备看门狗作为独立兜底。
7. 预览明确标为参数模型，非实测波形。保留原模拟模式，避免把双通道软件能力投射到当前硬件。
8. 交付前编译、协议伪串口及界面检查、按既有README要求构建与自检EXE；最后用户按连接→提交→启停→外部停止→退出→重新连接完成实物验收。

仍待验证：精确电压校准、A/B/PG实际安全输入、保护延迟定量测量、更长时间稳定性；双通道、随机/噪声/能谱等不属于当前硬件已完成能力。

## 5. V0.8.0图形上位机实物验收与版本冻结

2026-10-18按本聊天用户截图与现场确认整理；未由助手直接测量硬件。上位机保留原双通道模拟与通用流程，单通道台架模式使用独立参数/提交和状态轮询流程。

| 检查 | 结果 |
|---|---|
| 连接不自动启动 | GUI为IDLE/OK、FPGA在线，示波器无脉冲 |
| 提交并回读 | 基线16、幅度224、周期2000 μs、τ24 μs；CONFIG/OK，generation 2→3，启动可用 |
| 实际启动与停止 | RUN/OK，示波器500 Hz/2 ms；高采样率单脉冲约5.6 V，未见此前异常凹口；用户确认GUI停止后回基线 |
| 改幅度 | GUI停止后224→112重新提交；示波器幅度约2.88 V、基线2.88 V，停止回基线 |
| PA0外部停止 | 用户确认回基线，GUI同步IDLE/OK、FPGA在线、启动禁用；模型预览保留不代表实物仍输出 |
| 运行中断开与重连 | 用户确认正常停止并能重新连接，无自动启动 |
| 运行中关闭窗口与重开 | 用户确认正常停止并能重新连接 |
| 完整断电后仅用GUI操作 | 不重新下载，连接/提交/启动，持续60秒后安全停止；用户确认正常并通过 |

冻结范围：PC V0.8.0首页EXE及当前源码，STM32 F405-B2.0.0 bench HEX/ELF及源码，FPGA时序诊断FS/工程/RTL/约束/脚本与现有报告；并保留原FPGA通信版及基础版作为对照。各项以冻结包SHA-256清单确定文件身份。实际板载版本来自前述HELLO、User Code及用户验收，不能用复制文件的哈希代替板载内容读回证明。

冻结不重新生成硬件码流、不重刷设备、不占用COM口。保留已有构建/仿真/软件测试证据；新快照做复制一致性、归档完整性及PC源码语法复核，不暗称本次重新完成全部编译。

后续可靠性补测：用户正在进行30分钟连续运行与3轮完整断电启动；截至冻结时尚未提供最终结果，不记为已通过。现阶段仍保留安全旁路、未校准电压、未定量保护延迟及双通道/噪声/随机/能谱能力边界。
