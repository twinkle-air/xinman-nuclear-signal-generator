# 单通道核信号 N3：产物与实物调试

## 状态

本版目标是实际单通道DAC实时生成随机到达、按能谱分配幅度的单指数脉冲，并叠加可调有界均匀噪声。PC仅上传参数与256项能谱分位表，不循环播放预生成波形。

这是待实物验收的新版本。旧版的30分钟及3轮断电结果不自动继承到本版。当前安全输入旁路、电压未精密校准、保护延迟未定量等边界仍保留。

## 三项配套产物

| 部分 | 文件（工作区相对路径） | 身份 |
|---|---|---|
| 上位机 | 核信号工作台.exe | V0.9.0，兼容旧B2和新N3，原双通道模拟保留 |
| 外部STM32F405 | stm32_firmware/build-nuclear/nucsignal_f405.hex | F405-N3.0.0 |
| Gowin FPGA | FPGA_firmware/基础方案/核信号单通道_V3/impl/pnr/g1_dac_spi.fs | FPGA-3.0.0，版本寄存器0x00030000 |

STM32构建：`stm32_firmware/tools/build_nuclear.ps1`。输出独立到build-nuclear，不覆盖build-bench。N3只接受V3 FPGA；原B2只接受V2 FPGA，混用会离线。PC识别固件后才显示对应功能，不能给旧B2发送N3参数。

## 先用SRAM试运行

1. 安全停止并关闭旧上位机，保持现有接线、供电和探头条件不变。
2. Gowin Programmer选GW2A-18C、已验证的2.5 MHz下载线频率，先用SRAM Mode下载上表新FS，不覆盖原外部Flash。
3. 向**外部STM32F405**下载上表build-nuclear HEX，不是逻辑派板载GD32。保留原HEX和接线。
4. 打开根目录V0.9.0 EXE，选择单通道台架与实际CH340串口，连接。应回读F405-N3.0.0、IDLE/OK、FPGA在线，并出现随机/能谱/噪声控件。
5. SRAM配置断电会失效，外部Flash仍是旧V2；此时N3与V2不匹配而离线是预期。新功能验收前不要把断电恢复当作通过；重上电需重新SRAM下载V3，或按回退步骤恢复整套旧版。

## 分步实物验收

每一步均停止→修改→提交并回读→启动→观察→停止。停止后实际回到基线才记通过，不只看模型曲线。

| 步骤 | 配置 | 观察及通过条件 |
|---|---|---|
| 1 回归 | 基线96，最大幅度84，周期2000 μs，τ24 μs；随机/能谱关、噪声0 | 稳定负向单指数脉冲，500 Hz；STOP回活动基线 |
| 2 随机 | 同上，仅开启随机 | 周期栏表示平均间隔2000 μs；脉冲间隔变化，长窗统计平均约500事件/秒，允许随机涨落；可能尾巴堆积 |
| 3 能谱 | 开随机，勾选能谱，选择Cs-137内置理想模板，噪声0 | 提交上传并校验成功，幅度按模板分布；内置谱轴满量程2000 keV，最大幅度84码映射该满量程，Cs-137峰不会全等于84码。仅看示波器不足以证明完整能谱重建，需要脉高统计 |
| 4 噪声 | 在步骤3基础上噪声峰值2码 | 基线与脉冲叠加小幅噪声；峰值参数不是RMS。噪声置0重新提交后减小，STOP后噪声关闭 |
| 5 停止与恢复 | PC STOP、外部PA0、关闭窗口/断开 | 输出停止回基线，禁止自动恢复输出；重新提交后才允许启动。G1本地停止复位到默认16码并清能谱表，需重新上传提交 |

逐步验收后，再做新版本30分钟、断电固化、脉高直方图及随机到达统计。不要把单条截图或仿真当作真实能谱精度证明。

## 模型与能力边界

- 每1 μs最多一个事件，随机间隔为几何分布，是连续泊松到达的离散近似；平均间隔128–10000 μs。
- 1 μs单指数更新、脉冲叠加；统计事件数与削顶样点数。削顶会改变脉高谱，高计数率必须关注削顶计数。
- 能谱分位表256项，码值8位；小概率细节可能被量化丢失。内置模板是示意谱，没有完整探测器效率/响应，导入实测谱也需说明原采集条件和能量轴。
- 噪声为有界近似均匀噪声（±0–32码），本版不实现高斯/带限噪声。基线≥噪声峰值且基线+最大幅度+噪声峰值≤255；随机堆积仍可能饱和。
- 所有控制仍使用DAC码，不提供正式伏特/能量校准。示波器负向电压与PC正向DAC码模型的极性差沿用现有硬件。
