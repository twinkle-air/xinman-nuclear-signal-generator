# 智能仿核信号发生器——软件实现方案

版本：V1.2（FPGA-G1／ATK-MO8008 硬件适配修订）  
日期：2026-10-03  
定位：软件为硬件服务，负责文件转换、配置、统计验证、显示与可追溯记录；实时逐点输出由 FPGA 完成。

适配说明：本版以手头的立创逻辑派 FPGA-G1、高云 GW2A-LV18、正点原子 ATK-MO8008 V3.3 和 STM32F405RGT6 开发板为当前原型。原 V1.1 中的 AD9767 双路 14 bit／50 MSPS 方案及三块自制载板只保留为未来改版参考，不能作为现有硬件的已实现能力。DAC 具体芯片、数字输入门限、采样沿、输出电压范围和带载能力仍待模块资料与实物验证。FPGA-G1 板级记录见 [`FPGA-G1_开发参考.md`](../hardware/FPGA-G1_开发参考.md)。

版本提示：根目录同名 PDF 仍是 V1.1 旧版；当前硬件实施请以本文 V1.2 为准。

## 1. 软件交付目标

软件系统分为三层：PC 上位机、STM32 固件和 FPGA RTL。上位机将 TXT/Excel 中的“能谱”或“逐点波形”转换为统一设备数据，完成参数配置、预览、导入、运行控制和统计验证；当前 STM32 固件通过开发板 CH340／USART1 与 PC 通信，已编写 SPI1 FPGA 主机接口，但尚未与 FPGA RTL 和实物完成握手；计划由 FPGA-G1 用 8 bit 数据线和一条 DAC 时钟线驱动 ATK-MO8008 的一路 `DA_OUT`。当前阶段的输出能力以实测为准，不预设双通道或 50 MSPS。

推荐技术栈：现有 PC 上位机继续使用 Python／PySide6；STM32 固件使用 C 与现有构建工具链；FPGA 使用 Gowin EDA + Verilog，配合可用的 RTL 仿真器验证。FPGA-G1 不能用 Vivado 生成配置文件。最终 PC 发布形式在整机联调后确定。

### 1.1 当前原型硬件与未来载板

当前原型由 FPGA-G1、ATK-MO8008、外部 STM32F405 开发板组成。FPGA-G1 自带 GD32F303，但它不是本项目的 STM32F405 控制器。DAC 模块使用单独 5 V 供电时必须与 FPGA 共地，且不得把独立 5 V 与 FPGA-G1 板载 5 V 网络并联。当前没有已验证的 A/B/C 三块自制载板，也没有实测的板卡在位／PG 信号；只有安装相应硬件并验证极性后，才能启用这些安全检查。DAC 数字线从 H5 引出时先做低速短线实验，再依据示波器和时序报告决定是否需要连接器板或专用 PCB。

V1.1 的 889 元估价对应另一套 AD9767／自制载板 BOM，不能用于当前实物组合；成本和整机结构应在硬件清单确定后重算。

### 1.2 评分结论与软件补强重点

当前原型尚无 FPGA 配置文件和 `DA_OUT` 实测证据，不能依据 V1.1 的预估分数判断完成度。软件侧应把每一项功能落实为可重复核验的示波器波形、原始 CSV 和统计报告：

- 第一阶段验收固定码、斜坡和周期性单指数脉冲；记录 DAC 时钟、输出电压、脉冲周期和宽度。0.1 V 幅度档位、1 μs 宽度档位、50 kHz 与噪声指标在校准和采样率确认后逐项验证。
- 一键执行高级功能验收：256/1024道导入、输出峰值重建、Am-241/Cs-137/Co-60模板、Co-60双峰拟合和泊松间隔检验。
- 每次测试生成包含配置快照、固件/FPGA/校准版本、样本量、原始数据哈希、图表和结论的PDF/HTML报告；不以界面预览图替代实测。

## 3. 文件模型：必须区分“能谱”和“波形”

题目中的 TXT 可能有两种语义，软件不能靠猜测混用。

### 3.1 能谱文件（SPECTRUM）

每行表示“道号/能量、计数或概率”。支持 256 或 1024 行；计数必须非负且总和大于 0。

```
# type=spectrum
# channels=1024
# x_unit=keV
# energy_full_scale_keV=2000
0,0
1,0
...
338,1542
339,8231
...
1023,0
```

导入后步骤：解析 → 单位/道数验证 → 缺失道处理 → 去除负值/NaN → 概率归一化 → 构造 alias 表 → 预览直方图 → 打包下发。若第一列是能量而非道号，使用线性或用户指定标定关系重采样到 256/1024 道。

### 3.2 逐点波形文件（WAVEFORM）

每行表示采样点时间与归一化幅度。当前原型仅有一路 DAC 输出；目标采样率由已验证的 FPGA→DAC 时钟确定，上传前重采样并量化为 8 bit（码值 0–255）。例如 100 μs 波形在 1 MSPS 时为 100 点、在 50 MSPS 时才是 5000 点；不能预设后者可由排线和模块可靠实现。超出已验证存储容量的文件必须明确拒绝或分段。

```
# type=waveform
# time_unit=us
# amplitude_unit=normalized
0.00,0.0000
0.01,0.0135
0.02,0.0268
...
99.99,0.0001
```

转换规则：时间严格递增；归一化幅度范围建议 0–1；插值默认线性，可选零阶保持；重采样后先预览再上传；超出 0–1 的数据默认报错，只有用户显式选择“裁剪”才限幅。

## 4. 统一 `.sgen` 数据格式

`.sgen` 是可归档的设备中间文件，推荐采用“小型 JSON 头 + 二进制数据区”，便于版本演进与批量发送。

```
MAGIC      4 B   "SGEN"
VERSION    2 B   0x0100
TYPE       1 B   1=spectrum, 2=waveform, 3=scene
CHANNELS   1 B   1 or 2
META_LEN   4 B   JSON 元数据长度
DATA_LEN   4 B   二进制数据长度
META       N B   UTF-8 JSON
DATA       M B   little-endian 数组/alias 表
CRC32      4 B   从 MAGIC 到 DATA 的 CRC32
```

元数据必须包含源文件 SHA-256、导入时间、原始道数/采样率、目标采样率、量化方式、满量程、电压标定版本和软件版本。这样演示异常时可以追溯“是哪一个文件、怎样转换、由哪个版本发送”。

## 5. PC–设备传输协议

PC–STM32 使用二进制帧，避免用易歧义的文本命令传输大数组。当前固件通过板载 CH340／USART1（115200 8N1）与 PC 通信；原生 USB CDC 是未来可选迁移方向，不能当作现有接口。

```
SOF       2 B   0xA5 0x5A
VER       1 B   协议主版本
FLAGS     1 B   ACK_REQ / ACK / ERROR
CMD       2 B   命令号
SEQ       2 B   序号
LENGTH    4 B   payload 字节数，单帧建议 ≤1024
PAYLOAD   N B
CRC32     4 B   VER..PAYLOAD
```

| 命令 | 方向 | 功能 | 关键返回 |
|---|---|---|---|
| HELLO | PC→MCU | 协商协议/能力 | 固件／FPGA 版本、已验证输出通道数和实际具备的硬件状态 |
| GET_STATUS | PC→MCU | 查询状态 | 运行、错误、削顶计数；板卡在位、PG和温度仅在硬件具备时返回有效值 |
| SET_PARAM | PC→MCU | 写影子参数 | 参数校验结果、实际量化值 |
| COMMIT | PC→MCU | 原子提交 | 生效事件号/时间戳 |
| DATA_BEGIN/CHUNK/END | PC→MCU | 分块发送谱/波形 | 累计偏移、CRC、重传请求 |
| START/STOP | PC→MCU | 输出控制 | 状态回读 |
| SELECT_PRESET | PC→MCU | 选内置核素 | 模板 ID、版本、道数 |
| READ_HIST | PC→MCU | 读取事件统计 | 间隔/幅度直方图，可用于自检 |
| SAVE/LOAD_PROFILE | 双向 | 保存/载入设备配置 | profile ID 和校验和 |

可靠性规则：所有写命令必须 ACK；SEQ 去重；大文件每块 CRC，结束时再做整体 SHA-256/CRC32；超时重发最多 3 次；连接断开时保持最后稳定输出或按配置安全停止，默认安全停止。

## 6. 上位机界面

主窗口采用五区布局，减少比赛现场切页：

1. 左侧“信号源”：内置 Am-241/Cs-137/Co-60（K-40扩展）、导入能谱、导入波形。
2. 中央“波形预览”：显示理想脉冲、噪声叠加预览、削顶提示。
3. 右侧“通道参数”：当前仅启用 CH1 的幅度、τr、τd、FWHM、周期/平均间隔、噪声RMS百分比、PILEUP/NON_OVERLAP；未在 FPGA／DAC 实现的控件显示为不可用。竞赛模式目标为幅度步进≤0.1 V、FWHM步进≤1 μs、噪声步进≤1%FS，实际可用范围由校准数据决定。
4. 下方“设备状态”：连接、固件版本、FPGA 连通状态、CH1、错误码、削顶计数；CH2 只有接入第二 DAC 并验收后才显示可用。
5. 顶部大按钮：连接、下发、启动、停止；停止按钮始终可见且颜色固定。

参数控件必须显示设备量化后的实际值。时间参数提供两种互斥模式：直接时间常数模式设置`τr、τd`并只读显示所得FWHM；竞赛宽度模式设置FWHM和形状比`r=τr/τd`（默认0.2，`0<r<1`）再求解时间常数。幅度验收关闭噪声；噪声验收关闭脉冲或使用小幅脉冲。基线及可用输出电压范围由 ATK-MO8008 的 `DA_OUT` 和后续模拟电路实测确定，不能先写死为 0–5 V。确定性峰值加噪声可能超出实测范围时，软件拒绝启动或提示降幅；削顶必须在报告中披露。

## 7. 内置核素模型

内置模板用于模拟脉冲幅度分布，不声称替代具体探测器的完整响应。默认能量满量程 2000 keV，电压映射 `V = E/E_FS × V_FS`。

| 核素 | 主要参考峰 | 默认模板 | 可调参数 |
|---|---|---|---|
| Am-241 | 约59.54 keV | 单峰高斯 + 可选低能本底 | 峰宽FWHM、本底比例、计数率 |
| Cs-137 | 661.657 keV | 单峰高斯 + 可选连续本底 | 峰宽 FWHM、本底比例、计数率 |
| Co-60 | 1173.228、1332.492 keV | 双峰，权重默认近似相等 | 两峰宽度/权重、计数率 |
| K-40（扩展） | 约1460.8 keV | 单峰高斯 + 可选本底 | 峰宽、本底比例、计数率 |

核数据来源应在软件“关于/数据来源”中列明；IAEA/NNDC 数据用于峰位参考。若赛方提供标准谱，直接作为新的内置版本并记录 SHA-256。真实 NaI(Tl)、HPGe 等探测器的康普顿连续谱、逃逸峰和分辨率不同，因此最稳妥的比赛演示是同时展示“理想峰模板”和“导入实测 1024 道谱”。

必须把三个分辨率概念分开：题目的“幅度步进 0.1 V”是用户设置幅度档位的最小步进；256/1024 道是能谱概率分箱；现有 DAC 的数字输入只有 8 bit，即 256 个码值。能谱 1024 道可以保留为概率分箱，但最终事件峰值会压缩到至多 256 个未校准的 DAC 码值；0.1 V 档位和能谱峰分辨能力能否满足要求，要由实际输出量程、单调性、噪声和校准实测决定。

## 8. FPGA RTL 架构

### 8.1 当前阶段：单路 8 bit DAC 输出

```text
50 MHz/T7 ─> 复位同步／采样节拍 ─> test_source ─> dac_if ─> H5 D0–D7、CLK ─> ATK-MO8008 DA_OUT
                                 固定码／斜坡／单指数查表
STM32 SPI1 ─> spi_regfile ─> shadow_params ─COMMIT─> active_params ──────┘ （联调阶段接入）
```

1. 用 Gowin 建 GW2A-18、PBGA256、C8/I7、版本 C 工程；`sys_clk` 约束到 T7，输入 50 MHz、周期 20 ns。用户最新照片采用模块 40 针母座直接插入 H5；假定整排无错位且方向正确，DAC D0–D7 对应 H5-17～24（B14、A15、A12、B11、B12、C12、C11、A11），DAC `CLK` 对应 H5-25（C9）。上电前断电通断测量确认电源和排针方向，详见硬件参考的“当前实物：40 针直接插接”。原 H5-1～8／H5-9 是之前的单独跳线方案，不能用于当前直插约束；ADC 输出所接脚保持输入。
2. `test_source` 先生成 0、半量程、满量程固定码，再生成单调斜坡；下一步用 8 bit ROM 查表输出周期性单指数脉冲。波形表的长度、峰值、基线、周期使用参数或寄存器定义，预留以后切换成定点递推核心。
3. `dac_if` 只驱动模块上与 `DA_OUT` 对应、同组有 `CLK` 的 D0–D7；另一组 `CLK/OTR` 属于 ADC。数据和时钟都经触发器输出，从低速开始，依 DAC 器件确认采样沿并保证建立／保持时间；不能把板载 50 MHz 直接等同于已验证的 DAC 采样率。`DA_OUT` 接示波器或后续模拟输出电路。
4. 8 bit 输出限幅范围为 0–255。单指数宽度、幅度和周期先在数值模型中生成期望码序列，再与 RTL 仿真逐点对照；上板检查实际电压传递函数、码序单调性、脉冲宽度和周期。模拟输出的 0–5 V 范围与 0.1 V 档位需实测校准后才能承诺。

### 8.2 STM32 控制面：在固定波形稳定后接入

现有固件的约定以 [`stm32_firmware/docs/fpga_spi_register_map.md`](../../stm32_firmware/docs/fpga_spi_register_map.md) 和 [`stm32_firmware/src/fpga_link.c`](../../stm32_firmware/src/fpga_link.c) 为准：SPI1 Mode 0、MSB first、约 10.5 MHz；CS/SCK/MISO/MOSI 加 READY、IRQ、RESET。帧包含命令、地址、长度、数据、CRC32 和 ACK。FPGA 应先实现魔数 `0x4E534647`、版本及状态只读，使 MCU `probe` 可用，再做参数写入、`COMMIT`、`START/STOP` 和数据流。G1 H5/H6 到 STM32 的实际排针连接尚未冻结，需独立制作接线表并核对电平及复位极性。

`shadow_params` 接收新参数但不立即改变输出；`COMMIT` 在脉冲边界或停止状态将整组参数切换为 `active_params`，并回报 generation。READY 仅在可接收事务时有效；CRC 错误不能改变寄存器。STOP 必须使输出进入定义好的安全基线。固件已有两个通道的结构体并不代表第二条模拟通道存在，FPGA 能力查询只公布已验收的 CH1。

### 8.3 后续扩展

在 CH1、SPI 和模拟幅度标定通过后，再依次增加单／双指数定点核心、可控周期、泊松事件间隔、能谱 alias 抽样、事件叠加和高斯噪声。定点运算先选能覆盖中间值的内部位宽，最后一次性舍入和限幅到 8 bit；系数 Q 格式与流水线级数由误差及 Gowin 时序报告确定，PC 端维护同样舍入规则的位准确模型。随机流需要独立种子、无全零锁死，并保留原始事件样本供统计检验。第二条**独立模拟输出通道**需要第二个 DAC 通道或更换模块并重新定义约束和能力位；现有 ATK-MO8008 的 ADC 组不能当作第二个 DAC。

## 9. STM32 固件架构

| 任务/模块 | 周期/优先级 | 职责 |
|---|---|---|
| safety/status | 1 ms，高 | 看门狗、FPGA READY、错误锁存、停止请求；板卡在位和电源PG只在相应检测电路安装后启用 |
| fpga_link | 事件驱动，高 | SPI 事务、参数提交、状态读取、数据块搬运 |
| usb_protocol | 事件驱动，中高 | 帧解析、CRC、ACK、重传、能力协商 |
| storage | 低 | 内置/用户模板、配置、校准系数、版本迁移 |
| ui_input | 10 ms，中 | 旋钮/按键消抖、操作事件 |
| display | 100 ms，低 | 局部刷新，禁止高频全屏刷写 |
| log | 后台，低 | 环形日志、错误和运行统计 |

固件状态机：`BOOT → SELF_TEST → IDLE → CONFIGURED → RUNNING → ERROR`。当前原型先确认 FPGA SPI 魔数／版本、READY 和 STOP 路径；DAC 模块没有数字回读时，不能把 FPGA 可通信当作模拟输出已正常。未安装的 A/B/C 板在位或 PG 检测不得伪报为通过。只有 CONFIGURED/IDLE 可启动；ERROR 必须停止输出并显示原因。升级功能不是首版必须项，若加入，至少要有镜像 CRC 和失败回滚。

## 10. TXT/Excel 转换算法

### 10.1 能谱转 alias 表

1. 读取 256/1024 个非负计数 `c[i]`，拒绝总和为 0。
2. `p[i]=c[i]/Σc`，必要时根据目标道数守恒重采样。
3. 构建 Vose alias：输出 `prob[i]`（建议 Q0.32）和 `alias[i]`（10 bit）。
4. FPGA 抽样：随机取得列 i，再用第二随机数与 prob[i] 比较，返回 i 或 alias[i]。
5. 可选在道内均匀抖动，减少只落在离散电压点的视觉台阶。

### 10.2 指数系数

板载 50 MHz 的 20 ns 是 FPGA 系统时钟周期，**不是已确认的 DAC 采样周期**。设实测可用 DAC 采样率为 `Fs`、`Ts=1/Fs`，则递推系数可选 `α=round(exp(-Ts/τ)·2^23)`。上位机检查 α 是否量化为 0 或 2^23；若接近极限导致误差超标，提示实际可实现范围。双指数峰值归一化系数在 PC 端用高精度计算，避免 FPGA 除法。阶段一查表波形直接按选定 `Fs` 生成样点，无须先实现乘法递推。

竞赛宽度模式把“脉冲宽度”统一为FWHM。单指数按 `τd=FWHM/ln2` 反算，并把FWHM定义为从`t=0`峰值到下降半高点的等效半高宽；双指数由FWHM和形状比`r=τr/τd`唯一确定参数。直接时间常数模式允许设置`τr、τd`，但FWHM只读，避免三个相关参数被误认为可独立任意设置。

### 10.3 泊松间隔

对均匀随机数 `U∈(0,1]`，连续间隔 `Δt=-ln(U)/λ`，再量化到事件调度器的时钟 tick；该 tick 可为 FPGA 系统时钟的 20 ns，与 DAC 更新周期分开定义。上位机可生成 10^5 个参考间隔，与 FPGA 直方图对比。NON_OVERLAP 模式的间隔定义必须写入报告，因为它不再是原始无条件泊松到达。

### 10.4 高斯噪声

噪声是 CH1 基础脉冲验收后的阶段任务。候选实现为12个独立均匀流求和减6，再按目标 RMS 缩放；泊松与 alias 使用独立随机状态。噪声设定仍采用**输出端 RMS 占实测满量程的百分比**，目标 0–20%FS、1%FS 步进。8 bit 量化会影响低幅噪声统计；上位机需比较实测 RMS、偏度、峰度、自相关和 PSD，依据实际模拟输出范围生成校准表，并报告削顶与统计失真。

## 11. 测试与统计验证

| 层级 | 测试 | 工具 | 通过标准 |
|---|---|---|---|
| 单元 | TXT/Excel 解析 | pytest 参数化/模糊输入 | 正常文件无损；错误文件给行号和原因 |
| 单元 | CRC、帧拆包、重传 | pytest | 分片/粘包/错 CRC 均正确处理 |
| 单元 | alias 抽样 | Python Monte Carlo ≥10^6 次 | 分布差异在预设统计阈值内 |
| RTL | 固定码、斜坡和查表单指数 | Verilog testbench 与 Python 参考码序列 | 固定码和斜坡逐点一致；指数按已定义 8 bit 舍入规则逐点一致 |
| RTL | PRNG/泊松/噪声 | cocotb导出各流样本 | 均值、方差、直方图、自相关、跨流相关、短周期与全零锁死检查合格 |
| 集成 | 原子参数更新 | 逻辑分析/示波器 | 不出现半旧半新畸形脉冲 |
| 验收 | 单路重复频率 | CH1 在目标周期连续运行 60 s，示波器和内部计数共同记录 | 根据实际 DAC 时钟与模拟恢复能力逐档确认；双路各 50 kHz 需另一 DAC 通道后再测 |
| 验收 | 噪声RMS | 在已定义测量带宽下扫0–20%FS各档，记录每档原始样本量 | 扣除基线/模板后比较目标与实测RMS，记录偏度、峰度、PSD和削顶率；通过阈值以赛题和测量方案为准 |
| 系统 | 断连/掉电/错误文件 | 自动脚本 + 人工 | 默认安全停止，错误可恢复 |
| 验收 | 卡方检验 | SciPy `chisquare` 或自实现 | 报告分箱、自由度、p 值；建议 p>0.05 |

高级功能报告至少包含：输入谱与输出峰值直方图叠图、总变差距离（目标≤0.05，作为工程验收线）、卡方统计量及分箱方法；Co-60报告另外给出双峰拟合中心、峰间分离和两峰权重。泊松报告采集不少于10^4个间隔，同时给出指数分布直方图、Q-Q图、卡方/KS结果和均值误差。

卡方检验注意事项：期望频数过小的尾部箱应合并，不能为了获得好看的 p 值随意删样本；同时输出 QQ/直方图和 KS 检验作为辅助，不把单次检验结果当成绝对证明。

## 14. 风险与对策

| 风险 | 等级 | 影响 | 对策 |
|---|---|---|---|
| TXT 语义不明确 | 高 | 导入后波形完全错误 | 强制选择 SPECTRUM/WAVEFORM；支持元数据头；预览确认后才能发送 |
| 三端协议漂移 | 高 | PC、MCU、FPGA 互不兼容 | 先以现有 SPI 寄存器文档和固件代码为契约；版本化变更并回归 HELLO／probe |
| 浮点模型与 FPGA 定点结果不同 | 高 | 参数误差或验收失败 | PC 位准确 golden model；RTL 自动对拍 |
| 统计检验使用不当 | 中 | 随机性结论不可信 | 固定分析流程；保存原始样本；报告分箱/自由度/样本量 |
| GUI 阻塞影响传输 | 中 | 卡顿、丢响应 | 设备线程与 UI 线程分离；队列通信；可取消传输 |
| 断连后继续危险输出 | 中 | 操作风险 | 默认断连安全停止；设备本机 STOP 始终有效 |
| 原型板连接松动或供电冲突 | 高 | 间歇错误、损坏或输出异常 | 共地且不并联独立 5 V；核对 H5 1 脚、电平和供电顺序；实测后再定义 PG／在位监测 |
| DAC 采样率或模拟范围被预设 | 高 | 波形时序与幅度指标失真 | 先测可用 `Fs`、采样沿、输出范围及负载；PC 只展示已验证能力 |
| Windows 打包缺依赖 | 中 | 现场无法运行 | 干净电脑回归；离线安装包；USB 驱动和样例文件随包 |
| 临赛升级工具/固件 | 中 | 新缺陷/板卡不可用 | 联调通过后冻结；保留上一个可启动版本和 bitstream |

## 15. 验收清单

- 能导入合法 256/1024 道 TXT、CSV、Excel，并对负值、空文件、重复道、非数字、错误道数给出明确错误。
- 能导入逐点 TXT，按实测可用的 CH1 采样率重采样到 8 bit，显示量化前后误差和削顶点。
- 内置 Am-241、Cs-137、Co-60 可在PC和设备屏幕选择且版本一致；Co-60输出直方图呈双峰，K-40作为扩展。
- 当前 CH1 能输出固定码、斜坡和单指数，示波器记录幅度、周期及 FWHM；可调 50 kHz 目标在 DAC 时序和模拟波形通过后单独验收。
- 噪声设置采用0–20%FS输出端RMS口径、步进1%FS，自动扫完全部21档并导出测量带宽、校准与PSD证据。
- 所有参数下发后可回读，界面显示“设备实际值”而不是只显示输入值。
- 参数提交不会生成畸形脉冲；双通道独立配置和输出需第二 DAC 通道及模拟链路，不列为当前原型已通过项目。
- 泊松间隔、高斯噪声、能谱幅度均可导出原始样本并生成统计报告。
- 通信错误、USB 拔插、设备重启、错误 CRC 和中断传输均有确定行为。
- 当前原型拔掉 FPGA 控制连接或 READY 失效时，STM32 安全停止并报告链路错误；A/B/C 板在位监测在专用载板和检测电路落地后验收。
- Windows 离线包在一台未安装 Python 的电脑上通过全流程演示。

## 16. 第一版可执行任务清单

1. 冻结 `SPECTRUM` 与 `WAVEFORM` 两种 TXT schema，以及 `.sgen` V1。
2. 建立协议模拟器：没有硬件时，PC 仍能完成 HELLO、参数下发、分块传输和错误注入测试。
3. 完成 TXT/Excel 导入、预览和 alias 表生成，提交 golden vectors。
4. FPGA-G1 先实现固定码／斜坡／单指数查表并实测 `DA_OUT`，再接 STM32 SPI；随后实现参数化指数、泊松、能谱和高斯噪声。双通道先解决第二 DAC 硬件。
5. STM32 先实现 USB↔FPGA 桥和 STOP，再加 TFT、存储和脱机模式。
6. 用示波器和 PC 采样数据闭环校准；最后才做界面美化和安装包。
