# 单通道核信号输出 V3

配套：PC V0.9.0、STM32 `F405-N3.0.0`、本工程FPGA版本寄存器`0x00030000`。只生成单通道8位DAC码，保留原时序诊断版作为回退，不修改旧FS。

## 实现

- 50 MHz逻辑时钟，1 μs样点；DAC数据仍在下降沿后200 ns更新、上升沿前300 ns稳定。
- 固定周期或随机到达。随机模式每微秒比较独立xorshift32状态与`round(2^32/平均间隔)`，间隔为几何分布，是连续泊松到达的离散近似；每步最多一个新事件。平均间隔128–10000 μs，约100–7812.5事件/秒。
- 单指数Q16整数递推，新事件叠加已有尾巴，内部电平和最终DAC码均饱和。计数分别为事件次数和发生饱和的样点数；不是测量仪器读回的能谱。
- 能谱使用256字节等概率分位表，索引取幅度PRNG的低8位，表值0–255映射到配置最大幅度码。低概率细节和窄峰会被有限分位数/8位码量化，不能等同原1024道谱的无损重建。
- 噪声为有界近似离散均匀分布，范围±0–32码，每微秒刷新；使用独立种子流。不是高斯或带限噪声，也不是RMS参数。生成器为可复现伪随机源，不是物理熵源。
- START复位PRNG和事件/削顶计数，同种子同参数重放相同伪随机序列。STOP和250 ms通信看门狗关闭脉冲及噪声，回活动基线。板载本地停止键沿用复位逻辑，回默认基线16并清表；外部STM32 PA0/PC STOP保留活动基线。

## SPI增量协议

沿用V2的Mode0、656.25 kHz、帧CRC32、完整ACK后写入及原有寄存器。原8字节基线/幅度/周期/alpha和generation/control地址不变。

| 地址 | 长度/权限 | 含义 |
|---|---|---|
| 0x0004 | R4 | 0x00030000 |
| 0x0020 | R32 | clip1/0/event1/0/0/0/generation/error_flags，LE u32 |
| 0x0110 | R12/W12 | 扩展影子参数，仅停止可写 |
| 0x0120 | R12 | 扩展活动参数 |
| 0x0180 | W4 | 开始能谱上传，清完整位图及committed，仅停止可写 |
| 0x0184 | R4 | 全256项已写入为1，否则0 |
| 0x0200–0x02FF | R1/W1 | 分位表逐字节读写，仅停止可写 |

扩展参数：随机标志u8、噪声峰值u8、能谱标志u8、保留0、概率阈值LE u32、非零种子LE u32。随机/能谱标志只接受0/1。启用能谱时完整位图不满则COMMIT失败。修改表清committed；运行中改表、写参数、清表均拒绝。串口上传CRC由STM32检查，SPI每字节上传后读回比较。SPI返回数据本身沿用V2无响应CRC的限制。

## 构建和仿真

`scripts/build.ps1`使用Gowin V1.9.10.02综合/布局布线；`scripts/simulate.ps1`使用Vivado 2022.2 XSim进行RTL仿真，Vivado不生成Gowin码流。

`tb/nuclear_expected.hex`由PC整数参考模型生成，前12000点验证随机+双能级能谱+噪声，后6000点验证堆积削顶；参数与计数见同目录JSON。测试同时覆盖不完整表、坏CRC无副作用、运行中改表拒绝、STOP、看门狗和本地复位。保留原固定周期SPI回归。
