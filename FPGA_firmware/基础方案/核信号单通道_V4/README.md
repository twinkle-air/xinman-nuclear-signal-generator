# 单通道核信号 V4 / N4

配套PC V0.10.0、STM32 F405-N4.0.0；FPGA版本寄存器`0x00040000`。接线、板卡和模拟电路与N3保持一致。V3目录和N3 HEX未覆盖。

## 改进

- 固定周期10–10000 μs，20 μs对应数字调度50 kHz；随机平均间隔仍128–10000 μs。
- 单指数τ1–145 μs；PC提供理论半高宽`W=τln2`换算。更新步进仍1 μs，最短宽度的实测误差不能由数字模型消除。
- 均匀噪声仍为±0–32码峰值；新增1024项逆正态中点分位Q8表，RMS设置0–20%FS，1%步进。FS数字定义为255码；若要换算真实伏特，需外部校准及模拟传输测量。
- 高斯为有限尾部近似（约±3.30σ）；σ先转换为Q8码值，再乘Q8正态值并四舍五入。使用独立噪声PRNG，与PC整数参考一致。输出饱和会降低RMS、改变分布；削顶计数为样点数。
- 高斯计算分段流水，避开长乘法/除法路径。50 MHz逻辑不变；DAC下降沿后200 ns改数据，上升沿前300 ns稳定。
- 固定周期允许堆积需要PC/MCU显式开启；否则周期需≥5τ。随机模式自然允许尾巴叠加。
- 256字节能谱分位表维持N3兼容的传输与量化限制。PC新增量程/裁剪确认和量化预览，不宣称1024道无损输出。

## 扩展寄存器

0x0110影子/0x0120活动仍各12字节：随机u8、噪声幅度u8、能谱u8、选项u8、概率阈值LEu32、非零种子LEu32。选项bit0=高斯模式，bit1=允许固定堆积，其余位为0。均匀模式噪声字段0–32峰值码；高斯模式0–20 RMS百分数。其余CRC、上传、COMMIT和STOP流程保留。

## 构建与验证

从工作区运行`tools/generate_competition_vectors.py`生成N4整数模型夹具，然后运行本目录`scripts/simulate.ps1`和`scripts/build.ps1`。仿真不使用真实串口/板卡。

2026-10-19：SPI回归162项、核信号回归18540项、N4新增37091项；N4逐点比较37000个输出样点，含10/20 μs周期、长τ、高斯0/1/5/20%FS、随机叠加、削顶计数、STOP及本地复位。50 MHz布局布线建立/保持违例均0，报告Fmax65.446 MHz。

源码顶层、FS及报告均在本目录。模拟电压范围、50 kHz实际波形质量、噪声实测RMS/带宽、幅度±5%、Co-60双峰均待N4实物复测；不能继承N3的30分钟验收结论。
