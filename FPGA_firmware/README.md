# FPGA 软件：基础方案与进阶方案

全部 FPGA 程序、约束、工程、码流、连接表和日志都在本目录下，两套方案独立保存。

| 方案 | DAC硬件 | 当前功能 | 接线 |
| --- | --- | --- | --- |
| [基础方案](基础方案/README.md) | 正点原子 ATK-MO8008 V3.3，单路8位DAC | 固定码、斜坡、单指数；1 MSPS | 当前40针模块直接插H5 |
| [进阶方案](进阶方案/README.md) | KY_DAC_AD9767，双路14位DAC | 双通道固定码、斜坡、独立周期指数脉冲；每路1 MSPS | 同一G1/H5，但需要按[连接表](进阶方案/连接表.md)转接 |

KY模块36针J8与基础模块40针插座不兼容，**不能原样换模块直插**。进阶固件也不能在ATK模块仍插着时加载。原进阶方案的双路50 MSPS、SPI、随机事件、谱采样与噪声仍是后续目标，不能把本次联调固件称为完整高级功能实现。

## 选择工程

基础方案新增[通信联调工程](基础方案/通信联调/README.md)，配合STM32 `build-bench`使用；新增[H6控制连接表](基础方案/通信联调/连接表.md)。已有按键版及双通道进阶版继续独立保存。

- 基础：`基础方案/g1_dac_stage1.gprj`；码流：`基础方案/impl/pnr/g1_dac_stage1.fs`。
- 进阶：`进阶方案/g1_dual_dac_stage1.gprj`；码流：`进阶方案/impl/pnr/g1_dual_dac_stage1.fs`。

在相应方案文件夹中执行 `scripts/open_project.ps1`，按打印的英文盘符路径在Gowin中打开工程。旧工程已从本目录根部迁入“基础方案”，原先打开的旧路径需要重新打开；板上已下载的SRAM逻辑不会因电脑文件夹移动而改变。两版脚本分别编译/仿真，保留各自报告，仿真临时文件自动删除。

## 验证结果

- 两版重新完成 Gowin 综合、布局布线与码流生成，内部50 MHz setup/hold均无违例。
- 基础版 RTL 仿真通过2309个样本。
- 进阶版 RTL 仿真通过4388个双通道样本。
- 进阶版35个端口的位置与生成的IO约束逐个相符。
- 基础版已有用户SRAM Program至Finished截图；实测斜坡周期256 μs、脉冲周期1 ms，模式验证由用户报告通过，详见[实测记录](基础方案/reports/基础方案实测记录_2026-10-11.md)。进阶版尚无实物下载及输出测量。
