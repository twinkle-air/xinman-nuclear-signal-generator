# 进阶方案：FPGA-G1 + KY_DAC_AD9767

双通道 14 位 DAC 的第一阶段联调固件，独立于“基础方案”保存。建立日期：2026-10-03。

**使用前先阅读 [连接表](连接表.md)。KY 模块为 36 针 J8，不能原样代替基础版 40 针模块直插 H5；本版输出更多 GPIO，不得在 ATK-MO8008 仍接着时加载。**

## 当前实现

- FPGA：GW2A-LV18PG256C8/I7，版本 C，T7 板载时钟 50 MHz。
- DAC：KY_DAC_AD9767，MODE 高电平双口，2×14 位数据和各自 WRT/CLK，共 32 根输出线。
- 当前每路更新率 **1 MSPS**，数据提前 WRT 500 ns 更新，CLK 在 WRT 后 100 ns 更新。
- 两个通道拥有独立模式、斜坡状态、脉冲索引、重复周期和码表。顶层按键同时切换两路；核心 `mode_a/mode_b` 可以分别控制，仿真已检查混合模式和不重启另一通道。
- 上电固定码；key[0]/D11 循环“固定码→斜坡→指数脉冲”；key[1]/F10 复位。消抖与基础版一致。
- CH2 默认执行 `16383-logical_code` 数字补偿，因为该模块手册写明模拟通道 B 为反相输出；这是极性补偿，不能代替实测增益/零点校准。`CH2_INVERT` 可设为 0 做原始码测试。

| 模式 | CH1 | CH2（表中为补偿前逻辑码） |
| --- | --- | --- |
| 固定码 | 8192 | 8192，端口实际为8191 |
| 斜坡 | 步进16，1024个样本循环，约976.5625 Hz | 步进32，512个样本循环，约1953.125 Hz |
| 指数脉冲 | 基线8192，增量4096，τ=12 μs，周期1 ms | 基线8192，增量3072，τ=24 μs，周期1.5 ms |

脉冲码表前128点按 `baseline + round(amplitude*exp(-n/tau_samples))` 量化，其余回到基线；CH2在128点结束处存在有限截断量。本程序是双通道硬件联调与后续扩展起点，并未实现完整竞赛高级功能。

## 编译与打开

在本方案目录的 PowerShell 执行：

```powershell
.\scripts\open_project.ps1
.\scripts\build.ps1
.\scripts\simulate.ps1
```

`open_project.ps1` 建立指向本方案的英文盘符别名，打印实际 `.gprj` 路径；随后在 Gowin 使用 **File → Open** 打开打印的路径。它不依赖 Gowin 自动载入启动参数。两版分别创建别名，不能把基础版的盘符当作进阶版的盘符；检查打开后的工程名。

- 工程：`g1_dual_dac_stage1.gprj`；顶层：`g1_dual_dac_stage1`。
- 码流：`impl/pnr/g1_dual_dac_stage1.fs`。仅用于已经按本版转接表接好的 KY 双通道模块。
- Gowin V1.9.10.02 负责综合、布局布线及码流；Vivado 2022.2 的 XSim 只用于通用 RTL 仿真。
- `scripts/build.tcl` 明确使用三态弱上拉未用 GPIO、保留 JTAG，不复用 JTAG/MSPI/SSPI。
- 工具默认路径与基础版一致，可通过脚本参数覆盖。盘符别名是同一文件的另一条路径，不是文件复制；`.project-id` 用于验证别名确实对应本方案。
- 仿真结束删除 `.sim_work`；日志与实际编译报告保留供复核。

## 已验证与范围

本次 Gowin 综合、布局布线、生成码流均完成。内部50 MHz setup/hold违例均为0，最差setup slack **12.354 ns**；内部报告Fmax **130.789 MHz**不代表已验证的DAC速率。

资源：539个逻辑资源（报告3%）、138个寄存器（<1%）、35个I/O（3输入、32输出），无PLL/BSRAM/DSP。Bank7的16个可用I/O已全部占用，后续MCU接口需另选H6等可用接口并复核供电及复用。

仿真通过 **4388 个双通道采样点**，检查两路固定码、14位斜坡回绕、三个CH1／两个CH2脉冲周期、独立模式与周期、通道B补偿、1 MHz时钟、WRT/CLK顺序、500 ns数据建立/保持间隔、按键抖动／长按／复位。CST与实际生成IO约束的35个端口逐个一致。

目前SDC完成内部50 MHz时钟约束；外部DAC板级传播延迟、数据与WRT偏斜、WRT/CLK偏斜尚未签核。没有执行本版实物下载、示波器测量或Flash固化。确认转接硬件后，首次使用SRAM Program。

## 进阶目标与后续扩展

1. 两路DA实际波形与模块极性、幅度、增益、偏移校准。
2. 结合现有STM32 SPI V1协议增加影子参数、COMMIT、状态和通道独立控制；当前版本没有SPI从机，不能声称已经与现有MCU握手。
3. 增加可配置幅度、宽度、周期、单双指数、泊松到达、能谱alias与噪声。此版码表固定，不支持MCU上传波形或参数。
4. 原进阶目标双路50 MSPS需另做输出时钟/IP/流水线、板级时序和信号完整性验证。当前1 MSPS不代表该目标已经完成；已核对KY模块固定双口，因此不按旧方案的14线单口交织直接实现。
